Question Bank Retrieval

1. Questions

Format: optional count line, then one question per line: id unit co bloom difficulty, e.g. P1 1 CO1 K2 EASY. Bloom is K1–K6; difficulty is EASY, MEDIUM or HARD.

2. Query

Terms: unit=1 co=CO1 bloom=K3 bloom<=K3 bloom>=K2 maxbloom=K3 diff=HARD. Operators: AND OR NOT and parentheses. Adjacent terms are ANDed, so FIND unit=1 co=CO1 works. Add RANK easy=30 medium=50 hard=20 to order results by closeness to a difficulty mix.

3. Output

Load questions, then run a query.
